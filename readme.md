# TNTZO stem explorer

Companion page for Poster 10, IEEE EMBS Research Symposium 2026, UTS.
It shows all 26 printed femoral stem variants in 3D with their stress plots, the final stem in the femur model, and the final stem's engineering drawing.

The page is plain static files, so any static web host can serve it. Nothing needs installing or building.

```
index.html                              the landing page
app.js                                  the 3D viewer and data (three.js, bundled)
m/                                      models and stress plots, loaded on demand
TNTZO_A0_poster_IEEE-EMBS-2026.pdf      the poster, linked from the About section
FV6_engineering_drawing_PS2-42722-FV6-001.pdf
                                        the FV6 drawing, linked from the drawing viewer
```
